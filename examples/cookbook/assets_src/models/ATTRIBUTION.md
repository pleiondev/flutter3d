# Where the model comes from

| File | Author | Licence |
|---|---|---|
| `RobotExpressive.glb` | [Tomás Laulhé](https://www.patreon.com/quaternius), with facial morph targets added by [Don McCurdy](https://donmccurdy.com/); taken from the three.js examples | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) |

The same file is one of the fixtures in `packages/flutter3d_samples`, whose
`assets/ATTRIBUTION.md` records the same source. It is copied here so the
recipes load it the way a project of your own loads a model: from
`assets_src/`, by its path.
