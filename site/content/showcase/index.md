# Guides by capability

Every capability of the engine has a page of its own. Each page has three parts:
the demo, which runs live on your device, a guide that builds it from nothing in a
few steps, and the file that is running. Each is tagged with the version of the
engine it appeared in, taken from the CHANGELOG entry that first mentions it.

[Open the live showcase](/showcase/) to run the demos in your browser, or run it on
macOS with `flutter run -d macos` from `apps/flutter3d_showcase`. A guide here quotes
the same lines the app shows in its Step by step tab, because both are read from
the same files.
