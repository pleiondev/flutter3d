# What changed, by release

Every release of the engine, newest first. Under each one: the showcase pages
whose picture or behaviour it changed, and the pages it added. Each links to the
guide that builds it and to the live demo you can run in this browser. After
them, what the release changed in the Flame bridge, `flame_flutter3d`, which has
no showcase pages of its own: each line is the claim its CHANGELOG entry opens
with.

The list is read from the showcase's catalog, and every line in it quotes the
package CHANGELOG it came from, so it cannot claim a change the record does not
have. The full record, package by package, is in each package's CHANGELOG on
[pub.dev](https://pub.dev/publishers/pleion.dev/packages).
