# Models

All three are from Kenney's Space Kit, as the kit ships them: the files are
not changed. The game recolours each craft's accent material when it loads,
so the ship reads blue, a patrolling drone orange and a hunter magenta;
that happens at runtime and nothing on disk differs from the kit.

CC0 asks for nothing, so these tables are a note to ourselves rather than a
condition being met.
