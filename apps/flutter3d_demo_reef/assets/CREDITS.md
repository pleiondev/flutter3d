# Credits

Everything under `assets/models` and `assets/textures` was made by somebody
else first. All of it is CC0 1.0
(http://creativecommons.org/publicdomain/zero/1.0/), which asks for
nothing: this is a record, not a condition being met.

`tool/prepare_models.py` turns the downloads into the files below and says
beside each what was changed on the way; run it on a folder holding the
downloads, each unpacked into a folder of its own name as listed here, and
the result is the same files. Everything else on the reef (the coral, the
sea fans, sponges and whips, the amphora, the bell, the dive boat and the
diver's gear) is built in code from the engine's shapes.
