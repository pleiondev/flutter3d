## 0.6.0

* **In the workspace at the set's number, and deliberately not on pub.dev.**
  A new package, written after 0.6.0's own set had already been decided —
  same reason `flutter3d_cloth`/`flutter3d_game_strategy` carry this number
  unpublished: a pubspec that names every workspace package names one tree,
  whether or not every named package has gone out yet.
* `BoneMap`/`autoMap`: name a source skeleton's bones onto a target's, by
  the humanoid dictionary `anim-21`'s own `RigTemplate.humanoid` uses plus
  left/right pairing.
* `retargetClip`: rest-relative rotation retargeting, height-ratio-scaled
  translation, and a two-bone-IK foot lock that keeps the ankle at the
  ground plane after retargeting onto a differently proportioned rig.
