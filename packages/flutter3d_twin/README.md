# flutter3d_twin

Digital-twin data sources built on `flutter3d_sim`'s reading and binding
primitives — `tpl-04`'s own spindle reading is the first, `ls-i-00`.

Plain Dart, no Flutter SDK: a server checks or replays a twin's own signal
the same way it verifies a game run — by replaying it, in a container with
no Flutter SDK in it.
