# Publishing 1.0.0: the day's sheet

**First `1.0.0-rc.1`, then `1.0.0`.** Decided by Dmitrii on 2026-10-08.

How the release candidate works:

- **Constraints.** `^1.0.0` does not admit `1.0.0-rc.1`, because a
  pre-release sorts below its release. So every package asks its siblings
  for `^1.0.0-rc.1`. That constraint also admits the final `1.0.0`, so it
  stays as it is when 1.0.0 ships.
- **CHANGELOGs.** The top heading becomes `## 1.0.0-rc.1`. The final
  release adds a `## 1.0.0` section above it, listing only what changed
  since the candidate.
- **What users see.** pub.dev keeps 0.8.x as the default version. The
  candidate is opt-in, with `^1.0.0-rc.1`, and the caustics post says so.
- **Mistakes.** A published version can only be retracted, within 7 days.
