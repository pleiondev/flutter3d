## Высокая серьёзность

**1. Шутер: `FiredBy` стирается при restore снапшота → ракета после отката бьёт собственного стрелка, ресимуляция расходится.**
`flutter3d_game_shooter/lib/src/combat/projectile.dart:49` — `exclude<FiredBy>(...)`. В `flutter3d_sim/lib/src/ecs/component_store.dart:40` `inPlace => codec is InPlaceCodec`; у исключённого типа кодека нет, значит `EcsWorld.restore` (`ecs_world.dart:351`) чистит его store, а из файла ничего не возвращается. `projectile.dart:155` берёт `FiredBy.collider` как `ignore:` при трассе, `:175` — как владельца для зачёта. Сценарий: сетевой откат (`EngineRollback`) или `rewindTo` через кадр после выстрела → на ресимуляции ракета без `FiredBy`, луч не игнорирует стрелка, попадание в себя, зачёт ничейный, дайджест отличается от оригинала. Фикс: `InPlaceCodec` с пустым restore (как у `Gait`) или не чистить store исключённых типов. **Ч** (перепроверил сам).

**2. Детерминизм: позиции сущностей вложенных префабов считаются через libm.**
`flutter3d_sim/lib/src/level/prefab.dart:413` — `Matrix3.rotationY(parent.yaw).transformed(entity.position)`; `rotationY` внутри vector_math зовёт `math.sin/cos`, а не `Portable.sinCos`. Это раскрытие префабов уровня (`:342`, `:385`) — стартовые позиции тел. Структурное правило ищет текст `math.sin` и это не ловит. Сценарий: уровень с инстансом префаба при `yaw ≠ 0`, лента записана на VM, играется в браузере — позиции отличаются в последнем бите с шага 0, чекпоинт расходится, `SimulationVersion` совпадает, отказа «честного» не будет. Та же дыра правила: `Quaternion.axisAngle` в `flutter3d_physics_native/lib/src/native_ragdoll.dart:314` (после каста во float практически не проявится). **Ч** (перепроверил).

**3. Cloud `convertFiles`: чтение произвольных файлов хоста через ссылки внутри ассета.**
`flutter3d_build/lib/src/convert/in_memory.dart:122-126` проверяет `..`/абсолютный путь только у ключей загруженных файлов, не у ссылок внутри документов. `flutter3d_build/lib/src/convert.dart:764-772` (`fileUriResolverFor`): `File('$directory/${Uri.decodeComponent(uri)}')` без проверки, что результат внутри каталога. `convert/usd_input.dart:81,89` принимает абсолютные пути как есть. glTF с `"images":[{"uri":"../../../../etc/passwd"}]`, `.obj` с `mtllib ../..`, `.usda` с `@/Users/x/.ssh/id_rsa@` кладут байты в выходной `.f3d`, который возвращается клиенту. В CLI на своей машине некритично, в облачном сервисе — эксфильтрация. **Ч**.

**4. Откат не повторяет сдвиг origin для вьюхи, частиц и `CollisionWorld` (пункты 17–18, arch-review Should).**

Сценарий: сдвиг на шаге 100, `rewindTo(50)` → луп в origin A, сцена/частицы в B, всё, что в scene space, уезжает на величину сдвига до следующего сдвига.
- `shiftsPhysics` (`engine_loop.dart:585-591`, `originPart` в `flutter3d_physics/lib/src/collision_world.dart:1008-1033`) не вызывается ни одной игрой; для `NativeWorld` аналога нет вовсе (ядро origin в снапшот пишет, `csrc/src/f3d_snapshot.c:840`, хука нет). `Scene.rebaseAround`, `EngineLoop.shiftOrigin`, `followOrigin` — ни одного вызова вне тестов.
- Жанры конвертируют `body.position.toWorldPosition()` без origin: `flutter3d_game_platformer/lib/src/staging.dart:258,264`, `flutter3d_game_racing/lib/src/headless.dart:167,172`, `flutter3d_game_strategy/lib/src/headless.dart:238`, `flutter3d_demo_content/lib/shooter_staging.dart:417,423`, `flutter3d_sim_mcp/lib/src/sim_session.dart:569`. `Vector3.toWorldPosition()` (`flutter3d_foundation/lib/src/vectors.dart:43`) по умолчанию `origin = WorldPosition.origin`. После `shiftOrigin(B)` `HeadlessGame.position/eye` врут ровно на B; `playtest.dart:225-251` и слушатель аудио (`AudioListener.placeAt` тоже с origin по умолчанию) смотрят не туда.
- Возможен двойной сдвиг частиц: `Flutter3dEngine._shiftOrigin` сдвигает `_shiftFollowers` после `_scene.shiftOrigin`, а декларативный `Particles` (`flutter3d_app/lib/src/declarative/scene_widgets_features.dart:453`) сдвигает `_system` по `Scene.onOriginShift` — одна `ParticleSystem` в обоих уедет на 2×. **П**.
Всё латентно, пока origin никто не двигает. **Ч**.
