# Пост-обработка: flutter_scene 0.24.3 vs flutter3d (ветка 1.0.0, 2026-10-09)

Заметки агента. Источники. FS = `packages/flutter_scene/lib/src/…` в клоне на коммите «Release flutter_scene 0.24.3» (2026-10-08), шейдеры `…/flutter_scene/shaders/`. RS = `packages/flutter3d_core/lib/src/engine/render/render_settings.dart`; PP = `…/renderer_post_pass.dart`; шейдеры `packages/flutter3d_shaders/shaders/post/`. У flutter_scene почти всё — поля `Scene` (`scene.dart:1047–1061, 1698–1825`); у flutter3d — поля `RenderSettings` (RS:1481–1540), шаги `render_step.dart:514–547`, аддоны `packages/flutter3d_post/lib/src/*`. Бэкенды: FS — Impeller (Metal/Vulkan/GLES) + свой WebGL2; F3 — Impeller, WebGL2, WebGPU, CPU-растеризатор. Если бэкенд в строке не указан — эффект есть на всех бэкендах движка.

## 2. Чего нет

**У flutter3d нет (есть у flutter_scene):**
- Шейп боке (`bladeCount/Rotation/Curvature`) и quality-тиры DoF — средний вес, видимая разница в кадре.
- Bent normals, multi-bounce, specular AO, depth-mip chain в AO — средний; `visibilityBitmask` частично покрыт `ssil`.
- SSR: glossy blur, `resolutionScale`, fade, 6 debug-видов — средний (у F3 SSR заметно проще).
- Fog: linear-режим, `skyColorInfluence`, `sunInScatter` — низкий/средний (F3 компенсирует volumetric fog).
- SMAA runtime-тюнинг и диагональный поиск — низкий.
- Радиальные shockwave-импульсы (`ScreenDistortion`) — низкий, геймплейный эффект.
- Анимированное зерно — низкий (F3 намеренно статичное ради golden).
- Bloom firefly suppression / highlight compression — низкий, но защищает от NaN-вспышек.
- Per-node `debugView` и ~30 каналов, depth-gap — низкий/средний.
- `CustomRenderPass.drawObjects` (маска нод) + `shadowMap/shadowInfo` как вход кастомного прохода — средний для плагинов.

**У flutter_scene нет (есть у flutter3d):**
- Motion blur — высокий.
- Volumetric fog с кластерным светом — высокий.
- Local exposure, HDR output (WebGPU) — средний.
- Spatial upscale (EASU) + CAS-sharpen вне TAA — средний.
- TAA reactive mask, k-DOP clip, истории AO/contact — средний (меньше ghosting частиц).
- Halation, display transform (ACES 2.0/OCIO), dither — низкий/средний.
- Lens distortion barrel/pincushion — низкий.
- High contrast + colour-vision LUT — средний (доступность).
- Full-screen стадия в языке материалов, 51 якорь, `without/only` по шагам — средний для расширяемости.
- Per-view авто-экспозиция — низкий.

## 3. comparison.md (`site/content/reference/comparison.md`)

- **Стр. 9, 30, 108**: «read against flutter_scene 0.24.1» — устарело; 0.24.2/0.24.3 (CHANGELOG:1–17) пост-фич не добавили (TAA objectMotion на web починен, lean-шейдер), но дату/версию надо обновить.
- **Стр. 53** «Lens flares, radial lens distortion and .cube LUTs — Scene yes»: неточно. У Scene нет radial lens distortion (barrel/pincushion); есть `ScreenDistortion` — импульсы-кольца. Либо переформулировать, либо разбить строку.
- **Стр. 44** «Horizon-based AO and screen-space bounced light — обе yes»: верно, но Scene глубже (bent normals, multi-bounce, specular AO) — стоит оговорить в тексте ниже таблицы, как сделано для SMAA на стр. 118.
- **Стр. 45** «SSR, DoF, bloom, auto exposure — обе yes»: верно; не сказано, что DoF у Scene с формой боке и тирами, а SSR с blur/scale — та же оговорка.
- **Стр. 48** «Volumetric fog — Scene no», **стр. 50** motion blur, **стр. 51** local exposure/HDR, **стр. 52** TAA/FXAA/SMAA, **стр. 62** adaptive quality, **стр. 63** debug views, **стр. 102** high contrast — подтверждаются источником 0.24.3.
- **Стр. 118** «its SMAA tunes its search at runtime where flutter3d has the 1x mode only» — верно (`SmaaSettings`, PP:253).
- **Стр. 130** «Scene has god rays … may have more than its README and CHANGELOG say» — теперь можно сказать точно: больше нет (проверено по исходникам).
- **Отсутствующие строки** (обе стороны проверены): custom post-pass API с входами depth/normals/shadow (Scene yes; F3 yes с velocity/AO) — у Scene `shadowMap` как вход кастомного прохода, у F3 нет аналога в таблице; sharpen/CAS и spatial upscale (F3 yes, Scene no); TAA reactive mask (F3 yes, Scene no); frame capture с изображениями (обе yes, стр. 98 говорит только об MCP); per-view AA/renderScale override (Scene yes; F3 — через `RenderView.options`, не проверял до конца); display transform/ACES 2.0 (F3 yes, Scene no); screen-space shockwave distortion (Scene yes, F3 no); shader-less debug channels (F3 yes; Scene требует `debug_views` user-define, CHANGELOG:23).

Непроверенное: точный публичный список ресурсов, доступных кастомному `RenderNode` во flutter3d; парсер `.cube` во flutter3d (`CubeLut.parse` упомянут в доке RS:2746, файл не открывал); поля `RenderViewSettings` (видел только объявления `render_view.dart:267,283`); soft knee у FS-bloom (видел упоминание в доке `bloom_pass.dart:82`, параметра в `BloomSettings` нет).
